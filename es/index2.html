Clon Digital es un Saas desarrollado durante mi trabajo en dypsela. En la plataforma podias subir modelos 3d que se optimizaban para tener menos de 100k triangulos y texturas de menos de 1k para poder ser vistos en dispositivos de gama baja y realidad virtual. En esta plataforma desarrollé el backend en nodejs en una instancia de AWS. La base de datos donde guardabamos la información era de postgres en una instancia RDS de amazon. Los modelos 3d se podian usar para crear salas donde automaticamente se les asignaba un colisionador y una experiencia multijugador, done podias moverte y hablar con otras personas. También podías añadir pdfs, videos otros modelos, luces para cambiar la visibilidad y los administradores de la sala tenian el control para prohibir el acceso a otros usuarios o permitirles hablar. Los modelos también se podían ver en Realidad aumentada. Debajo de este parrafo se encuentra el link a clondigital y a una de las salas para probar la experiencia.
